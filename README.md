# TodoList App

## Technologies Used

- React
- React Icons
- LocalStorage
- CSS

## What I Built

This is a simple and interactive Todo List application. The main features include:

- **Add, delete, and complete todos**
- **Search** 
- **Filter** 
- **Delete all** 
- **Persistent storage** 
- **Responsive and clean UI**


## What I Learned

- How to build a React app from scratch using Create React App.
- Managing state with React hooks (`useState`, `useEffect`).
- Passing props between components and lifting state up.
- Using LocalStorage for persistent data.
- Implementing search and filter logic in React.
- Handling user input and form submissions.
- Using icon libraries for better UI/UX.
